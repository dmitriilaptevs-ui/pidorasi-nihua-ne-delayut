# Российская AI API Platform

Проект платформы доступа к AI-моделям за рубли через собственные API-ключи и OpenAI-совместимый API. Рабочее название; публичный сервис пока не запущен.

## Статус

- Подготовлены требования, целевая архитектура и план совместной работы.
- В `main` ранее добавлен **`rubai-main.zip`** — отдельный Next.js-прототип. Он сохранён без изменений; его исходники не импортированы в рабочее дерево. [Статический обзор](docs/ARCHIVE-REVIEW.md) не заменяет запуск тестов или security-аудит.
- Целевой стек из ТЗ — **Next.js + TypeScript, FastAPI, PostgreSQL, Redis**. В архиве backend реализован в Next.js; дальнейший путь необходимо согласовать.
- Приложение, инфраструктура, реальные платежи и provider-интеграции в рамках этой подготовки не запускались. Готовность MVP и его критерии приёмки **не подтверждены**.

> **Стоп-условие ТЗ:** до начала разработки требуется письменное согласование перепродажи и обслуживания клиентов из РФ с поставщиком. До коммерческого запуска также нужны законная схема закупки, платежи/фискализация, защита данных и эксплуатационная приёмка. Текущая работа — документация и анализ. См. [этап 0](docs/STAGE-0.md).

## Основные принципы

1. Клиент получает ключ платформы, никогда — серверный ключ OpenRouter.
2. Платные запросы проходят через наш gateway: авторизация → лимиты → атомарный резерв → provider → фактический расчёт → финансовый журнал.
3. Предоплата и денежные операции — в целых копейках; тарифы/FX и накопление малых стоимостей — точная десятичная арифметика.
4. Ошибка или обрыв streaming не доказывают отсутствие расходов. Неопределённые затраты требуют сверки.
5. Пользовательские и финансовые данные обрабатываются и хранятся в РФ; трансграничная передача промптов рассматривается отдельно.
6. Provider adapter заменяем; смена поставщика не меняет клиентские ключи и балансы.

## Как присоединиться

Каждый участник использует собственный GitHub-аккаунт и клон. Если авторизация уже настроена, повторный login не нужен.

```bash
gh auth login --hostname github.com --git-protocol https --web
gh auth setup-git --hostname github.com
gh repo clone dmitriilaptevs-ui/pidorasi-nihua-ne-delayut
cd pidorasi-nihua-ne-delayut
```

Затем прочитайте [CONTRIBUTING.md](CONTRIBUTING.md), согласуйте задачу и создайте отдельную ветку. Публичность репозитория не даёт другу права push: при необходимости владелец приглашает его в **Settings → Collaborators**.

**Не коммитить:** реальные API-ключи, `.env`, персональные данные, платежные реквизиты, договоры, дампы и backups. `.gitignore` — только вспомогательный барьер, не проверка секретов, особенно внутри ZIP.

## Следующий шаг

Вдвоём сделать review документации, закрыть условия этапа 0 и решить, какие части архива переиспользовать. После разрешения на разработку — финансовая схема и OpenAPI, затем mock gateway и биллинг. Реальные запросы не включаются без проверенных резервов и учёта.

Собственные GPU, обучение моделей, полноценный AI-чат и сложное управление командами — вне MVP.
