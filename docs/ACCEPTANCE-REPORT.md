## 3. Внешние зависимости (нужны от владельца)

1. **YooKassa sandbox**: `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` (`test_…`) в `apps/web/.env.local` — живая проверка A-02/A-03.
2. **Yandex ID**: создать приложение (redirect `…/api/auth/callback/yandex`, scope `login:info`) и положить `YANDEX_CLIENT_ID/SECRET` — живой вход (A-02 цели, identity).
3. **VK ID для публичного адреса**: нужен собственный домен (или проверенный base domain), т.к. приложение зарегистрировано на `localhost`.
4. **Финальный прогон из РФ** на подтверждённом владельцем адресе.
