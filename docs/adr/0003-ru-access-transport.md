# ADR-0003: Транспорт доступа из РФ без VPN

**Статус:** открыто — решение принимается по результатам измерений (задача `ru-access`).
**Контекст:** российский пользователь должен открыть продукт без VPN. Кандидаты должны переживать типовые блокировки и не прятать страну клиента от провайдера. Сервер находится в DE.

## Кандидаты

| № | Вариант | Плюсы | Риски |
| --- | --- | --- | --- |
| 1 | Прямой HTTPS/443 на IP в DE | Ноль дополнительных компонентов | IP может попасть в реестр; домен/SNI может блокироваться |
| 2 | Cloudflare перед origin (проксирование) | Бесплатно, привычный TLS, смена IP без смены домена | Доступность CF из РФ, ограничения CF на длительные/не-HTML потоки |
| 3 | Российский фронт (Selectel/Yandex Cloud) + шифрованный обратный туннель до DE | Домашний IP, устойчивость к реестру | Платная инфраструктура, нужен туннель, R-03 частично закрывается |
| 4 | Альтернативные транспорты (WebSocket/HTTP-2/3, domain fronting) | Обход SNI-фильтров | Хрупкость, сложность поддержки, вопросы ToS |

## Метод оценки

- Измерения: доступность и задержка с российской потребительской точки (владелец), стабильность TLS/streaming, поведение при блокировке домена/IP.
- Критерии выбора: воспроизводимость у российских провайдеров, отсутствие платной зависимости без согласия владельца, эксплуатационная простота, возможность fallback.
- Fallback и rollback описываются до включения публичного трафика.

## Последствия

- Решение фиксируется здесь после измерений; до этого публичный запуск использует вариант с наименьшим риском.
