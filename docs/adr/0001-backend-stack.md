# ADR-0001: Модульный монолит FastAPI + PostgreSQL + Redis

**Статус:** принято владельцем (2026-10-05), уточняет D-02.
**Контекст:** прототип `apps/web` реализует BFF route handlers в Next.js; ТЗ и [ROADMAP](../ROADMAP.md) предполагают FastAPI + PostgreSQL + Redis. Нельзя вести два независимых источника баланса и сессий.

## Решение

- Backend — модульный монолит на Python/FastAPI в `apps/api`: identity, ключи, каталог, ledger, gateway, платежи.
- PostgreSQL — единственный источник истины по пользователям, ключам, финансам и usage; Redis — лимиты, кеш, очереди (не финансовая истина).
- Next.js `apps/web` остаётся интерфейсом и обращается к API; серверные route handlers прототипа используются только как переходный слой и выводятся из эксплуатации по мере переноса identity.
- Миграции — с первого коммита; финансовые суммы — целые копейки и точные десятичные типы.

## Последствия

- Понадобятся контейнеризация, миграции, тесты на pytest и отдельный контур секретов.
- Временные in-memory сессии прототипа (потеря при рестарте) заменяются durable-сессиями в БД.
- Перенос VK/Яндекс OAuth из BFF в API выполняется как отдельный шаг с сохранением PKCE и одноразовых state.
